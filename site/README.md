# site/ — the kauk.ai projection

Static projection served at **kauk.ai**. One repo serves all `kauk.ai/<pkg>` pages,
generated at publish (the projection rule). Host-agnostic — deploy to GitHub Pages (org
`kaukai`, MVP) or AWS S3+CloudFront (see `docs/TODO.md.d/kauk-ai-hosting.md`).

- `CNAME` — `kauk.ai` (GitHub Pages custom domain).
- `.nojekyll` — disable Jekyll; serve files as-is.
- `index.html` — the landing page.
- `packages/<pkg>/index.html` — one projected page per package (`example/` is a placeholder
  showing the layout; real pages are generated by the `projection` functionality).

## Deploy (GitHub Pages)

Push this directory as the `kaukai` org Pages repo; enable Pages; the `CNAME` sets the custom
domain. DNS: point `kauk.ai` at GitHub Pages (A/AAAA apex records or an ALIAS).
