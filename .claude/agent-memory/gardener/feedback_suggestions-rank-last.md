---
name: suggestions-rank-last
description: Agent-suggested tasks/features always rank AFTER operator-validated tasks in any list, render, or launch summary
metadata:
  type: feedback
---

In any board render, priority list, launch summary, or triage offer:
operator-validated tasks come first, in their own order; anything the agent
itself surfaced or is proposing (new intake, options, scope additions) trails
them, clearly marked as suggestion — part of triage, never presented as peer
or above validated work.

**Why:** Operator, 2026-08-18 — a launch summary mixing agent-suggested scope
with validated tasks read as the agent inventing features and implementing
them without permission ("suggestions always go after established tasks, they
are part of triage, not above what the operator already validated").

**How to apply:** Separate the sections or order strictly: validated first,
suggested last with an explicit "suggested" marker. Applies to every
operator-facing list. Related: [[task-references-use-titles]].
