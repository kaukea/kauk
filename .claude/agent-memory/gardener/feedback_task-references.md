When speaking to the operator about board tasks, lead with the task TITLE (the
short title from the board line); an issue number may trail as an identifier but
never stands alone.

**Why:** Operator, 2026-08-18 — "do not quote GitHub issue numbers only as if I
knew all of them by heart. They have a title." Bare gh# references forced him to
look up every mention.

**How to apply:** In every board render, triage offer, and status line: "the
stale-laid-links repair (gh#21)" or just the title — never "gh#21" alone.
